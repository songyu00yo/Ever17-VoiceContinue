# Changelog

## v1.0.0

### 中文

首个公开版本。

- 添加 Voice Continue。
- 保持原速，不排队，不重叠。
- 使用机器码特征扫描，提高对不同 2002 PC 汉化/整合 EXE 的兼容性。
- 自动备份并支持 `/restore`。
- 提供中英文 README、技术说明和兼容性反馈模板。

### English

First public release.

- Adds Voice Continue.
- Keeps original playback speed with no queueing or overlap.
- Uses machine-code signature scanning for broader compatibility with 2002 PC translation patches and repacks.
- Creates backups automatically and supports `/restore`.
- Includes Chinese and English README files, technical notes, and compatibility report templates.
