# Ever17 Voice Continue

给 **2002 PC 版 `Ever17 -the out of infinity-`** 补上现代 GAL 常见的 **Voice Continue / 语音延续** 行为。

## 效果

- 翻到**无新语音**的下一句：上一句语音继续播放；
- 下一句出现**新语音**：上一句立即停止，新语音立即开始；
- **原速**；
- **不排队**；
- **不重叠**。

## 为什么需要这个补丁

老 PC 引擎默认在翻页时会触发角色语音淡出/停止。  
简单拦截 `Stop()` 又会导致后续语音排队，因此本补丁只修改**“翻页触发语音停止”**的两条底层路径，保留**“新语音替换旧语音”**的原生逻辑。

## 兼容性

v1 最初只按一个汉化 EXE 的固定偏移修改。当前版本已经改为 **PE 可执行节代码特征扫描**：

- 不检查固定 SHA-256；
- 不检查固定文件大小；
- 不依赖 EXE 文件名；
- 不依赖固定文件偏移；
- 对代码中的绝对地址、`CALL rel32` 等版本相关字节使用通配匹配；
- 只有两段目标 KID 引擎代码都被**唯一识别**时才允许写入。

因此，**只要某个汉化组/整合包仍基于同一套 2002 PC KID 引擎代码，哪怕修改了资源、文本、时间戳、文件大小、镜像地址或部分外围代码，也有较高概率直接兼容。**

> 这不意味着“所有 Ever17 版本”都通用。2011 Xbox 360 重制、2025 版以及底层引擎例程被重写的 PC 修改版不在目标范围内。遇到未知代码布局时，本程序会拒绝修改，而不是猜偏移硬打补丁。

目前实测基准：

- 2002 PC 中文整合/汉化 EXE（SHA-256 `f90b13f6f4b6840c79ed338230f988b5617bab7786307e35445689a78f21471f`）

欢迎提交其他版本的测试结果。

## 使用

1. 把 `Ever17_VoiceContinue.exe` 放进游戏 EXE 所在目录；
2. 双击运行；
3. 程序自动扫描目录中的 x86 PE，找到唯一匹配的 Ever17 2002 PC 引擎 EXE；
4. 首次安装会创建：
   `游戏.exe.voicecontinue.bak`
5. 安装完成后会启动游戏。

以后可以直接运行已打补丁的游戏 EXE，也可以继续双击本程序当启动器。

### 还原

命令行：

```bat
Ever17_VoiceContinue.exe /restore
```

补丁会根据仍保留在目标代码块中的引擎地址关系重建原始 5 字节指令，而不是依赖某个固定版本的硬编码地址。

## AudioSpeedHack / ZeroInterrupt

**不要同时启用 ZeroInterrupt。**

ZeroInterrupt 的工作方式是拦截 Stop 并对语音排队缓冲，这会把游戏在“新语音出现时停止旧语音”的正常 Stop 也吞掉，结果就是：

`旧语音 -> 后续语音排队等待`

如果游戏目录存在 `dsound.dll` / `MMDevAPI.dll`，补丁会询问是否临时改名禁用。不会直接删除文件。

## 安全设计

- 只扫描 PE 的 executable sections；
- 两条特征都必须分别唯一命中；
- 两条代码必须同时处于“未打补丁”或“已打补丁”状态；
- 匹配到部分修改、多个候选或未知引擎时直接停止；
- 首次写入前创建备份；
- 安装后重新扫描验证；
- 不修改剧情脚本、存档、`voice.dat`、BGM、SE 或语音文件。
